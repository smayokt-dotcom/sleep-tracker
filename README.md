# 🌙 Sleep Tracker — Ver 1.0

Huawei Health アプリのスクリーンショットから睡眠データを自動抽出し、グラフで可視化する PWA（Progressive Web App）です。

**🔗 デモ:** https://smayokt-dotcom.github.io/sleep-tracker/

---

## 主な機能

| 機能 | 説明 |
|---|---|
| 📸 スクショ取込 | Huawei Health の睡眠画面を撮影→アップロードするだけで Gemini API がデータを自動抽出 |
| 📊 グラフ表示 | 睡眠時間 / 就寝・起床 / ステージ / スコア / 覚醒回数 を週・月・年で表示 |
| 👆 スワイプ操作 | グラフを左右スワイプで 1 データ（1 日/1 ヶ月）ずつ細かく移動 |
| 📅 カレンダー | 今日の日付ボタンからカレンダーを表示、データのある日をタップでその週へジャンプ |
| 🛌 仮眠分離 | 夜間睡眠と仮眠を別色の積み上げ棒グラフで可視化 |
| ✏️ 手動編集 | 抽出値が誤っていた場合にモーダルから修正可能 |
| 📤 エクスポート | 全データを JSON ファイルとして保存 |
| 📥 インポート | 別端末からエクスポートした JSON を読み込んで復元 |
| 📱 PWA | ホーム画面に追加してネイティブアプリのように使用可能 |

## セットアップ

### ローカル開発

```bash
git clone https://github.com/smayokt-dotcom/sleep-tracker.git
cd sleep-tracker
# 静的ファイルなのでそのままブラウザで開くか、ローカルサーバーを使用
npx serve .
# または
python -m http.server 8080
```

### Gemini API キーの取得

1. [Google AI Studio](https://aistudio.google.com/app/apikey) にアクセス
2. 「Create API key」でキーを生成
3. アプリの **設定タブ** → **APIキー** 欄に貼り付け
4. 「テスト」ボタンで疎通確認

> APIキーは端末の localStorage にのみ保存されます。外部サーバーには送信されません。

## 使い方

### 1. スクリーンショットの取込

1. **追加タブ** を開く
2. Huawei Health の睡眠詳細画面のスクショを選択（JPEG / PNG）
3. Gemini API が自動解析し、各フィールドに値を入力
4. 内容を確認して「保存する」

> **自動保存（デフォルト ON）:** 設定タブで有効にしていると抽出完了後に確認なしで自動保存されます。

### 2. グラフの見方

ホーム画面に以下のタブが表示されます：

| 種別タブ | 内容 |
|---|---|
| 睡眠時間 | 1日ごとの合計睡眠時間（棒グラフ）。仮眠があれば夜間睡眠（紫）＋仮眠（オレンジ）の積み上げ表示 |
| 就寝/起床 | 就寝・起床時刻の推移（折れ線グラフ）。Y軸が逆転しており就寝が上・起床が下 |
| ステージ | 深い睡眠 / レム睡眠 / 浅い睡眠 / 覚醒の積み上げ棒グラフ |
| スコア | Huawei Health のスコア（取込時）or 内部計算スコアの推移（折れ線グラフ）|
| 覚醒回数 | 夜間に目覚めた回数（棒グラフ）|

#### 期間タブと操作

- **週 / 月 / 年** タブで集計期間を切替
- 年表示は月ごとの平均値
- グラフ右端に **平均値ライン** と数値ラベルを表示
- PC はホバー、スマホはタッチでその日のデータをツールチップ表示

#### ナビゲーション

| 操作 | 週タブ | 月タブ | 年タブ |
|---|---|---|---|
| ◀ ▶ 矢印 | 7日ジャンプ | 30日ジャンプ | 12ヶ月ジャンプ |
| スワイプ | 1日ずつ | 1日ずつ | 1ヶ月ずつ |

- 矢印を押すとスワイプ累積分はリセットされ、ユニット単位できれいに動く
- スワイプは未来方向には今日を越えられないようクランプされる
- 日付ラベルは実際のウィンドウ範囲を表示（例：「4/22 – 5/21」「2025年6月 – 2026年5月」）

### 3. カレンダーナビゲーション

ヘッダーの **日付ボタン**（例：`2026年4月27日(月)`）をタップするとカレンダーが開きます。

- 紫背景の日 = データあり
- 枠線の日 = 今日
- 日付をタップ → その週のグラフへジャンプ

### 4. データの編集・削除

**データタブ** の一覧から各レコードの ✏️ / 🗑️ ボタンで操作できます。

## データ仕様

### レコード形式

localStorage のキー `st_records` に JSON 配列として保存されます。

```json
{
  "id": "1714234567890",
  "date": "2026-04-23",
  "bedtime": "23:20",
  "wake_time": "07:05",
  "sleep_duration_min": 465,
  "deep_sleep_min": 98,
  "light_sleep_min": 267,
  "rem_sleep_min": 100,
  "awake_min": 12,
  "awake_count": 2,
  "nap_min": 66,
  "sleep_score": 82,
  "notes": null,
  "created_at": "2026-04-23T12:00:00.000Z"
}
```

| フィールド | 型 | 説明 |
|---|---|---|
| `id` | string | タイムスタンプベースの一意ID |
| `date` | string | `YYYY-MM-DD` 形式 |
| `bedtime` | string | 就寝時刻 `HH:MM`（24時間）|
| `wake_time` | string | 起床時刻 `HH:MM`（24時間）|
| `sleep_duration_min` | number \| null | 合計睡眠時間（分）。仮眠ありなら「合計睡眠時間」、なしなら「夜間の睡眠」を取得 |
| `deep_sleep_min` | number \| null | 深い睡眠（分）|
| `light_sleep_min` | number \| null | 浅い睡眠（分）|
| `rem_sleep_min` | number \| null | レム睡眠（分）|
| `awake_min` | number \| null | 夜間覚醒時間（分）|
| `awake_count` | number \| null | 夜間に目覚めた回数 |
| `nap_min` | number \| null | 仮眠時間（分）|
| `sleep_score` | number \| null | Huawei Health の睡眠スコア（0-100点）|
| `created_at` | string | ISO 8601 形式の登録日時 |

### localStorage キー一覧

| キー | 内容 |
|---|---|
| `st_records` | 睡眠レコード配列（JSON）|
| `st_gemini_key` | Gemini API キー |
| `st_settings` | アプリ設定（autoSave など）|
| `st_gemini_model` | 使用する Gemini モデル名 |

## OCR ロジック（Gemini プロンプト要点）

スクリーンショットから以下のルールでフィールドを抽出します：

| フィールド | 抽出ルール |
|---|---|
| `sleep_duration_min` | **「合計睡眠時間」が画面にあれば最優先**（仮眠込みの値）。なければ「夜間の睡眠」直下の `X時間XX分` を変換 |
| `nap_min` | 「仮眠 X時間XX分」表記から抽出。存在しなければ null |
| `sleep_score` | スター評価や「XX%のユーザーより上」と一緒に表示されている大きな数字＋「点」を抽出。「深い睡眠の持続性」などサブスコアは除外 |
| `deep/light/rem_sleep_min` | 「深い睡眠 2時間28分」「浅い睡眠 2時間51分」「レム睡眠 1時間19分」から各々抽出 |
| `awake_count` | 「目覚め 3回」「覚醒回数」などから整数で取得 |
| `bedtime` / `wake_time` | 24時間表記、深夜跨ぎは `00:30` 等そのまま |
| `date` | `M/D` 形式しか取れなければ現在年で補完。未来日付になる場合は前年に倒す |

> **画像圧縮:** アップロード時に長辺 1024px へリサイズし、JPEG 品質 0.85 で送信（API コスト削減）

## 睡眠スコアの計算式（内部フォールバック）

`sleep_score` フィールドが取得できなかったレコードについては、以下のロジックで 0〜100 点を算出します。Huawei スコアが取れていればそちらを優先表示します。

### 1. 睡眠時間スコア（`durScore`）

理想睡眠時間を **7.5 時間（450 分）** として偏差を評価します。

| 理想からの偏差 | 計算式 |
|---|---|
| ±30 分以内（7〜8h）| `95 − 偏差 × 0.17`（最大 95pt）|
| ±30〜90 分（6〜9h）| `90 − (偏差 − 30) × 0.67`（50〜90pt）|
| それ以外 | `max(0, 50 − (偏差 − 90) × 0.5)` |

### 2. 睡眠ステージスコア

データがある項目のみ評価し、平均を取ります。

| 項目 | 理想比率 | 計算式 |
|---|---|---|
| 深い睡眠 | 20% | `max(0, 100 − |実績比率 − 0.20| × 500)` |
| レム睡眠 | 22% | `max(0, 100 − |実績比率 − 0.22| × 400)` |
| 覚醒時間 | 少ないほど良 | `max(0, 100 − 覚醒比率 × 800)` |

### 3. 合成

```
最終スコア = durScore × 55% + ステージ平均 × 45%
```

> ステージデータがない場合は `durScore` のみで算出し、**上限 75 点** に制限されます。

## グラフ仕様

### スライディングウィンドウ

| タブ | ウィンドウ幅 | 集計単位 |
|---|---|---|
| 週 | 7日 | 1日ごと |
| 月 | 30日 | 1日ごと |
| 年 | 12ヶ月 | 1月ごと（平均値） |

矢印は **ユニット単位ジャンプ**、スワイプは **1棒ずつ細かく移動**。

### スワイプ実装

- `touchstart` で開始位置を記録、`touchmove` の最初の 8px で水平/垂直を判定
- 水平優位（dx > dy × 1.3）と判定されたときのみ `preventDefault()` で縦スクロールをブロック
- 棒1本ぶんの幅（= chart 幅 ÷ 棒数）を超えるごとにオフセット±1

### 睡眠時間グラフの色分け（仮眠あり時）

- 紫 (`#7c6fff`): 夜間睡眠 (`sleep_duration_min − nap_min`)
- オレンジ (`#ff9800`): 仮眠 (`nap_min`)
- ツールチップに「夜間: 6h 38m / 仮眠: 1h 6m / 合計: 7h 44m」を表示

### 期間サマリ（グラフ下のカード）

選択中のグラフタイプに応じて表示内容が変化：

| グラフ種別 | カード1 | カード2 | カード3 |
|---|---|---|---|
| 睡眠時間 | 平均 | 最長 | 最短 |
| 就寝/起床 | 就寝平均 | 起床平均 | 平均時間 |
| ステージ | 深い平均 | レム平均 | 浅い平均 |
| スコア | 平均（点）| 最高（点）| 最低（点）|
| 覚醒回数 | 平均回数 | 最多 | 最少 |
